# Quicklink

**A simple, secure URL shortener built with React and Spring Boot.**

Quicklink lets users create shorter, shareable URLs, manage their links, control link visibility, and set expiration dates.

## Features

- User registration and authentication
- Create short URLs from longer destination URLs
- Manage created links through a dashboard
- Control link visibility
- Set optional expiration dates
- Redirect short URLs to their original destinations
- Protected user and admin functionality
- Automated unit, web-layer, repository, and integration tests

## Architecture

Quicklink uses a layered Spring Boot backend with a separate React frontend.

- **Frontend:** Renders the UI and communicates with the backend over HTTP.
- **Controller layer:** Handles incoming requests and HTTP responses.
- **Service layer:** Contains application business logic.
- **Repository layer:** Handles database access through Spring Data JPA.
- **Database:** PostgreSQL stores persistent application data.
- **Security:** Spring Security manages authentication and authorization.

The React frontend and Spring Boot backend run separately during development, with Vite proxying the configured requests to the backend.
